# ЭтноСфера

Интерактивный MVP цифрового атласа народов России, созданный по `ТЗ_ЭтноСфера.md`.

Проект использует локальную SQLite-базу в `data/ethnosfera.db`. В ней подготовлены четыре пилотных региона, шесть народов, связи между ними, темы и стартовые истории.

## Запуск

```powershell
npm.cmd install
npm.cmd run db:seed
npm.cmd run dev
```

Команда `dev` запускает одновременно локальный API на `http://127.0.0.1:8787` и интерфейс Vite, обычно на `http://localhost:5173`.

## Production-сборка

```powershell
npm.cmd run build
npm.cmd run preview
```

Собранная версия находится в папке `dist/`.

## Что реализовано

- SQLite + Drizzle-схема для регионов, народов, связей, тем и историй;
- локальный API: `/api/regions`, `/api/peoples`, `/api/stories`;
- адаптивная стартовая страница и навигация;
- интерактивная схема карты с выбором региона;
- список народов выбранного региона и фильтрация публикаций;
- карточки народов с визуальными паттернами;
- каталог новых публикаций;
- тематические блоки;
- пошаговая форма добавления универсальной публикации;
- добавление нескольких файлов в форму;
- переключатель языка интерфейса в прототипе.

## Технологии

- React + Vite + TypeScript;
- Express API;
- SQLite через LibSQL;
- Drizzle ORM;
- Lucide icons.

## Ограничение текущей версии

Это локальный MVP. Авторизация, сохранение публикаций через форму, файловое хранилище, AI-модерация, коллекции и административная панель пока остаются интерфейсными прототипами. Следующий этап: запись публикаций и файлов в SQLite через API, затем замена SQLite на PostgreSQL для серверного развёртывания.
