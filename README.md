# ЭтноСфера

Прототип цифрового атласа народов России по техзаданию `ТЗ_ЭтноСфера.md`.

Живая версия: **https://foorin.github.io/etnosfera/**

Для входа в личный кабинет подойдёт любая почта и пароль. Чтобы увидеть кабинет
с готовыми материалами, войдите как `alina@example.ru` с паролем `etnosfera`.

## Что это

Работающий прототип интерфейса на демонстрационных данных. Он показывает устройство
сайта и пользовательские пути, но ничего не сохраняет: аккаунт, созданные материалы
и коллекции живут в памяти вкладки и сбрасываются при обновлении страницы.

Всё содержимое — 104 материала, народы, темы, регионы и населённые пункты — лежит
в `src/data/`. Это придуманные тексты, нужные только для показа.

## Что реализовано

- **Главная** — вращающийся глобус, поиск по атласу, подборки по темам, свежие материалы.
- **Карта по уровням**: Земля → Россия → регион → населённый пункт. Настоящие координаты,
  реки и рельеф, масштабирование колесом с привязкой к курсору.
- **Каталог народов** с фильтрами по региону и языковой группе.
- **Страницы темы и материала**: фильтрация по народу, региону и теме одновременно,
  хлебные крошки, галерея под число фотографий.
- **Коллекции**: свои и чужие подборки, добавление материала, настройки доступа, удаление.
- **Личный кабинет**: вход и регистрация, публикации со статусами, черновики, портфолио,
  настройки профиля с приватностью и удалением аккаунта.
- **Редактор материала** на отдельной странице с большим полем для текста.

У каждого экрана свой адрес, поэтому ссылкой можно поделиться и страница переживает F5.
Исключение — вход: аккаунт намеренно не сохраняется.

## Чего пока нет

Крупные разделы ТЗ, не вошедшие в прототип: инициативы, жалобы и модерация, уведомления,
административная панель с аналитикой, выгрузка портфолио в PDF, метаданные галереи,
проверка размеров файлов, перевод интерфейса на марийский. Кнопки, за которыми стоит
эта работа, помечены в интерфейсе как заготовки.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm ci
npm run dev:web
```

Откроется по адресу, который напечатает Vite — обычно `http://localhost:5173`.

## Сборка и публикация

```bash
npm run build
npx gh-pages -d dist
```

Первая команда собирает статику в `dist/`, вторая выкладывает её в ветку `gh-pages`,
откуда GitHub Pages раздаёт сайт. Обновление занимает 1–3 минуты.

Если после публикации в браузере остаётся старая версия, откройте ссылку с любым
параметром — например, `?v=2`: страница кешируется на стороне GitHub около десяти минут.

## Папка server/

`server/` — задел на будущее: Express с SQLite и схемой Drizzle. **Сейчас он не используется.**
Интерфейс работает на данных из `src/data/`, обращается к одному адресу `/api/regions`
и при его отсутствии спокойно продолжает с демонстрационными данными. На GitHub Pages
бэкенда нет вовсе, потому что Pages раздаёт только статику.

Запустить вместе с API, если понадобится:

```bash
npm run db:seed
npm run dev
```

## Стек

Vite + React + TypeScript, d3-geo и данные Natural Earth для карт, рукописный CSS.
Техзадание предполагает другой стек — Next.js, PostgreSQL, MapLibre, Tailwind, — и при
переходе от прототипа к рабочей версии этот выбор нужно будет подтвердить или пересмотреть.
